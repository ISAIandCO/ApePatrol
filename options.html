Параметры SEC AI Assistant

Сервисы для получения информации по IP-адресам:
При добавлении дополнительных сервисов по проверке IP-адресов в качестве шаблона для подстановки IP-адреса следует использовать последовательность ${ip}.
Пример: https://your-favorite-ip-check-service.net/api/path/${ip}/info



Сервисы для получения информации по хешам:
При добавлении дополнительных сервисов по проверке хешей в качестве шаблона для подстановки хеша следует использовать последовательность ${hash}.
Пример: https://your-favorite-hash-check-service.net/api/path/${hash}/info
