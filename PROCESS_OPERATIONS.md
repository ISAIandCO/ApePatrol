# Операции процессов

Общий интерфейс и правила работы описаны в [ApeShareCore/PROCESS_OPERATIONS.md](https://github.com/ISAIandCO/ApeShareCore/blob/feat/process-operations/PROCESS_OPERATIONS.md).

Требуется ApeShareCore 1.6+. Сначала интегрируйте PR общей библиотеки, затем PR расширения. Штатный резолвер продолжает выбирать совместимый `main`, без постоянной фиксации SHA или ветки. Для проверки ещё не интегрированных веток: `APE_CORE_SOURCE=../ApeShareCore npm run build:self-hosted`.

Настройки → «Операции процессов»: проверьте и включите нужные профили, сохраните, затем перезагрузите граф. Правый клик по процессу → категория → загрузка до 25 событий. Linux/Unix требует отдельного профиля нормализатора; стартовые Sysmon-профили Windows не применяются к Unix.
