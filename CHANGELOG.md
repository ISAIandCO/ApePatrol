# Changelog

## 3.4.26

- Добавлены отдельные профили Windows Security и Linux auditd с условиями сбора, обязательным классификатором, отображением действия/результата и настройкой строкового PID. Новые рекомендации добавляются без перезаписи сохранённых профилей.

- Операции выбранного процесса в пошаговом графе через ApeShareCore 1.6: файлы, сеть, DNS, реестр, доступ к процессам и модули.
- Страницы по 25 событий через существующий API MP SIEM, сортировка время + ID; общий редактор профилей операций.
- Стартовые профили требуют проверки и включения для конкретного источника; без GUID точность сопоставления явно ограничена.

## 3.4.25

- Общий редактор фильтров ApeShareCore 1.5: создание, поля, переключатели и проверка шаблона.
- Импорт/экспорт JSON сохранён; шаблоны PDQL редактируются в отдельном многострочном поле.

## 3.4.24

- Встроенные и пользовательские фильтры разделены через ApeShareCore; добавлены копирование, отдельное сохранение и импорт/экспорт JSON.
- Старые изменения встроенных фильтров сохраняются как пользовательские; поддержаны статические PDQL-условия и миграция профилей/управляемых политик.

## 3.4.23

- Проверяется сохранение выбранного события в графе при совпадении PID с другим событием. Исправление находится в ApeShareCore 1.3.1 и общее для ApePatrol и KumApe.

## 3.4.21

- Общий контроллер AI подключён ко всем чатам; проверяются адрес отправки, актуальность предпросмотра и запрет повторной отправки.
- Хранение снимков графа использует общую проверку схемы и лимиты.
- Длинные AI-вложения сохраняются в рамках бюджета 2 MiB без обрезки по лимитам карточек расследования.

- Графы процессов и расследований, страницы, AI payload и хранение перенесены в ApeShareCore 1.2.
- SIEM-адаптер сохраняет PDQL, API, извлечение полей и специализированные функции.
- Добавлен статус расследования и исправлено сохранение позднего AI-ответа при переключении диалогов.
