    Features

    Process graph limits

    Search scope

    Внешние IOC-ссылки

    Провайдеры открываются только после клика по обезьянке у конкретного поля. Поддерживаются ${ip}, ${hash}, ${domain} и ${url}.

    Custom filters

    Each template declares placeholders such as ${event_src.host}. The preview uses central PDQL escaping.

    Field aliases

    JSON object keyed by correlation name, plus optional default.

    API-проверка IOC

    Firefox требует два независимых действия: отдельно разрешить передачу IOC/API-ключа и отдельно доступ к endpoint каждого провайдера. Ключи можно сохранить заранее; они остаются только в storage.local.
