    External link providers

    These providers only open a safe HTTP(S) URL. Use ${ip}, ${hash} or ${url}.

    Custom filters

    Each template declares placeholders such as ${event_src.host}. The preview uses central PDQL escaping.

    Field aliases

    JSON object keyed by correlation name, plus optional default.

    VirusTotal

    Hash and API-key transmission remains disabled until configured and granted separately.

    SEC AI Assistant

    The assistant is disabled by default. Every request previews the destination, transmission mode and visible fields.
