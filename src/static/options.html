    Features

    Progressive process graph

    Граф сначала загружает небольшой seed-контекст, затем подгружает интервалы по явному действию оператора.

    Search scope

    Внешние IOC-ссылки

    Провайдеры открываются только после клика по обезьянке у конкретного поля. Поддерживаются ${ip}, ${hash}, ${domain} и ${url}.

    Custom filters

    Each template declares placeholders such as ${event_src.host}. The preview uses central PDQL escaping.

    Field aliases

    JSON object keyed by correlation name, plus optional default.

    API-проверка IOC

    Firefox требует два независимых действия: отдельно разрешить передачу IOC/API-ключа и отдельно доступ к endpoint каждого провайдера. Ключи можно сохранить заранее; они остаются только в storage.local.

    VirusTotal

    Хеши, IP, домены и URL.

    AbuseIPDB

    Репутация публичных IPv4/IPv6 за последние 90 дней.

    Kaspersky OpenTIP

    Хеши, IP, домены и URL.

    ThreatFox

    Поиск IOC и связанных семейств вредоносного ПО.

    Batch IOC

    SEC AI Assistant

    The assistant is disabled by default. ApePatrol shows the exact final request body and its UTF-8 byte size before every transmission. Local heuristics are warnings, not DLP.

    Enterprise Profiles

    Export содержит только non-secret settings. Managed policy может задать defaults и locked paths через Firefox storage.managed.
